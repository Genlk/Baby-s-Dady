# 闲置手机改造宝宝监控指南

把家里不用的旧手机变成 **24 小时宝宝监控摄像头**，主力手机随时远程查看。

## 推荐方案

```text
┌─────────────────┐     WiFi      ┌──────────────────┐
│  闲置手机 × N    │ ────────────▶ │  家用电脑/树莓派   │
│  （监控端 App）   │   每 5 秒上传  │  （分析服务器）    │
│  固定在宝宝房间   │               │  FastAPI + AI     │
└─────────────────┘               └────────┬─────────┘
                                           │
┌─────────────────┐     WiFi               │
│  主力手机        │ ◀──────────────────────┘
│  （家长端 App）   │   查看所有监控点 + 告警
└─────────────────┘
```

一台分析服务器 + 多台闲置手机 = **多房间全覆盖**，无需买专用摄像头。

---

## 第一步：准备分析服务器

在**一直开机的设备**上运行（旧笔记本、台式机、NAS、树莓派均可）：

```bash
cd baby-monitor
pip install -r requirements.txt
bash scripts/download_models.sh
uvicorn api.server:app --host 0.0.0.0 --port 8000
```

记下这台设备的局域网 IP，例如 `192.168.1.100`。

---

## 第二步：配置闲置手机（监控端）

### 硬件准备

| 项目 | 建议 |
|------|------|
| 手机数量 | 每个房间 1 台（儿童房、客厅等） |
| 支架 | 手机支架或万向夹，对准婴儿床/活动区 |
| 供电 | **必须插电**，避免半夜没电 |
| 网络 | 连接家里 WiFi，信号稳定 |
| 镜头 | 用后置摄像头，画质更好 |

### 软件设置

1. 安装 App（`flutter build apk` 生成的 APK）
2. 首次打开 → 选择 **「闲置手机 · 监控端」**
3. 进入设置（监控端右上角可切换）→ 填写服务器地址：`http://192.168.1.100:8000`
4. 点击监控点名称，改为「儿童房」「客厅」等
5. 点击 **「开始监控」**

### 省电技巧

- 开启 **息屏省电**（黑屏但摄像头继续工作）
- 系统设置 → 显示 → 屏幕超时设为 **30 分钟** 或 **永不**
- 关闭不必要的后台应用
- 关闭自动更新（避免半夜重启）

### Android 额外设置

- 设置 → 电池 → 对该 App 选择 **「不限制后台」**
- 设置 → 应用 → 宝宝智能监控 → 权限 → 允许 **摄像头、网络**

---

## 第三步：主力手机（家长端）

1. 安装同一个 App
2. 选择 **「主力手机 · 家长端」**
3. 设置中填写同一服务器地址
4. 打开 **「家中监控」** 标签页，即可看到所有房间

家长端每 5 秒自动刷新，显示：
- 实时画面（带姿态标注）
- 当前行为（睡眠、爬行、站立等）
- 异常告警（跌倒、无人看护）

## 常见问题

### 监控端显示「上传失败」
- 检查手机和服务器是否在同一 WiFi
- 检查服务器是否正在运行：`curl http://192.168.1.100:8000/health`
- 检查防火墙是否放行 8000 端口

### 家长端看不到监控点
- 确认监控端已点击「开始监控」
- 确认监控端服务器地址配置正确
- 等待 5～10 秒后下拉刷新

### 旧手机发热
- 开启息屏省电模式
- 降低上传频率（默认 5 秒，可在代码中调整）
- 确保通风，不要盖住手机

### iPhone 做监控端
- 必须插电，iOS 后台限制较严
- 保持 App 在前台或开启「低电量模式」以外的正常模式
- 建议 Android 旧机做监控端，iPhone 做家长端

## 进阶：无电脑，纯手机方案

若不想开电脑，可将服务器部署到：
- **云服务器**（阿里云/腾讯云轻量，约 ¥30/月）
- **树莓派 4**（约 ¥300 一次性，低功耗常开）
- **旧安卓手机**（装 Termux + Python，同时跑服务器）

家长端和监控端的服务器地址改为云服务器公网 IP 即可。
